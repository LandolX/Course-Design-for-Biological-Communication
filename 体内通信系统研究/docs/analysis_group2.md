### 论文1 (1808.04273)
**标题**: A Molecular Communications Model for Drug Delivery

**核心贡献**:
- 首次从通信工程视角系统分析了基于分子通信的药物递送系统中的**拥塞（congestion）**现象
- 提出了基于排队论的接收端模型，将每个受体建模为 **M/M/1/1 纯损失排队系统**
- 证明了接收端表面分子浓度分布的不均匀性导致受体并非可复用的资源池，而是隔离的服务单元
- 提出的模型与 BiNS2 仿真结果高度吻合，优于传统的"对称模型"

**关键方法**:
1. **扩散方程**：使用 Fick 第二定律描述药物分子从 TX 到 RX 的传播
   ```
   ∂c(t,r)/∂t = D∇²c(t,r)
   ```
   脉冲响应：
   ```
   h_Q(t,r) = Q/(4πDt)^(3/2) · exp(-r²/(4Dt))
   ```
2. **排队论模型**：
   - 每个受体 = M/M/1/1 队列（单服务器，无等待空间）
   - 到达率 λ_a = k⁺ · c(t,r) · (R_RX - i)
   - 服务率 μ = i/T_traff（trafficking time）
   - 拒绝率 λ_r 由忙受体碰撞引起
3. **非均匀浓度分布**：受体距离 TX 的距离不同，面临不同的局部浓度
   ```
   r(α) = √[(d + R_RX sin(α))² + (R_RX cos(α))²]
   ```
4. **整体拒绝率**：
   ```
   λ*_r = Σ λ*_{r,j} = Σ [λ*_{a,1}(d+r_RX)/r(α_j)] / [r(α_j)/(λ*_{a,1}(d+r_RX)T_traff) - 1]
   ```

**数学模型**:
- 扩散过程：3D 自由扩散，Fick 第二定律
- 受体结合：birth-death Markov 过程，状态依赖的到达率
- 拥塞检测：利用吸收率 λ*_a 的测量值反推系统参数

**仿真/实验结果**:
- 使用 BiNS2 仿真器（Java，3D 粒子级仿真）
- 参数：T=310K, η=0.0011 Pl, r_RX=2.5μm, R_RX=10000, T_traff=2s/4s
- Q-Q 图验证了分子到达过程符合泊松分布
- 提出模型与仿真高度吻合，对称模型低估拒绝率达一个数量级
- 受体位置不均匀性导致面向 TX 的半球吸收量是背面的两倍以上

### 论文2 (1811.00417)
**标题**: Diffusive Mobile MC for Controlled-Release Drug Delivery with Absorbing Receiver

**核心贡献**:
- 首次提出**移动药物载体**（移动发射机）与**吸收性接收端**（靶向病变细胞）的 3D 时变 MC 信道模型
- 推导了时变 CIR 的**一阶矩（均值）**和**二阶矩（方差）**的闭合表达式
- 推导了时变 CIR 的 **PDF** 和 **CDF**
- 设计了**最优控释曲线**（tri-phasic release），在确保吸收率不低于阈值的前提下最小化总药量
- 揭示了忽略载体移动性会导致严重的性能下降（与 naive 设计相比，最优方案节约 27%-54% 的药量）

**关键方法**:
1. **移动发射机-吸收接收机模型**：
   - TX 为球形透明发射机，半径 a_tx
   - RX 为球形吸收接收机，半径 a_rx
   - TX 遵循布朗运动，扩散系数 D_Tx
   - 药物分子扩散系数 D_X
2. **时变 CIR**（给定距离 r(t)）：
   ```
   h(t,τ) = a_rx/r(t) · 1/√(4πD_Xτ³) · (1 - a_rx/r(t)) · exp(-(r(t)-a_rx)²/(4D_Xτ))
   ```
3. **距离分布**：TX-RX 距离 r(t) 服从非中心 chi 分布
   ```
   f_{r(t)}(r) = r/(r₀√(πD_Tx t)) · exp(-(r²+r₀²)/(4D_Tx t)) · sinh(r₀r/(2D_Tx t))
   ```
4. **CIR 均值的闭合形式**：
   ```
   m(t,τ) = a_rx/[4√(π(D_Xτ+D_Tx t)r₀τ)] · exp(-a_rx²/(4D_Xτ) - r₀²/(4D_Tx t)) · [...]
   ```
5. **受控释放优化问题**：
   ```
   min A = Σ α_i
   s.t. E[g(t)] - βΓ[g(t)] ≥ θ(t), ∀t ∈ [0, T_Rx]
   ```
   转化为线性规划求解

**数学模型**:
- 信道：3D 自由扩散 + 移动 TX + 吸收 RX
- 距离分布：非中心 chi 分布（k=3）
- 优化：线性规划（基于均值和标准差的约束）
- 性能评估：P_θ = Pr[g(t) ≥ θ(t)]，使用 Chebyshev 不等式给出下界

**仿真/实验结果**:
- 粒子级布朗运动 Monte-Carlo 仿真（10⁵ 次独立实现）
- 参数：D_X=8×10⁻¹¹ m²/s, a_tx=0.1μm, a_rx=1μm, r₀=10μm, T_Tx=24h
- 均值与方差的分析结果与仿真高度一致（考虑了 TX 在 RX 边界的反射）
- 最优释放曲线呈现三阶段特征（tri-phasic）：初期高释放 → 中期低释放 → 末期高释放
- D_Tx 越大，末期释放量增加越快（TX 漂离 RX）
- β=1 时 P_θ 始终高于 0.75 的下界

### 论文3 (2112.12485)
**标题**: On the Reception Process of Molecular Communication-Based Drug Delivery

**核心贡献**:
- 建立了 **M/M/N_r/N_m** 排队系统模型来描述有限受体、有限容量环境下的药物分子接收过程
- 区分了两种拒绝机制：**受体饱和导致的拒绝** vs **分子随机运动导致的拒绝**（全新的贡献点）
- 推导了药物释放速率的**上下界区间**[Q_min, Q_max]
- 给出了状态依赖的 unbinding 率 μ_i 和 rejection 率 γ_i 的显式表达式

**关键方法**:
1. **排队论框架**：M/M/N_r/N_m 排队系统
   - 到达率 λ：恒定，由扩散方程确定
   - 离开率：μ_i（unbinding）+ γ_i（rejection），状态依赖
   - 最大容量 N_m：由接收空间体积和分子半径决定
     ```
     N_m = floor((4π/3)(R_e³-R_r³) / ((4π/3)R_a³))
     ```
2. **进入率**（稳态浓度）：
   ```
   λ = Q/(4πDRΔt)
   ```
3. **拒绝率 γ 的推导**（M/M/1/1 系统 → 推广到 M/M/N_r/N_m）：
   ```
   γ = (√(μ²+4λ²) - μ)/2
   ```
4. **状态依赖的退出率**：
   ```
   μ_i = Σ_{k=0}^{i} (i-k)μ   (i ≤ N_r)
   γ_i = Σ_{k=0}^{i} (i-k)γ   (i ≤ N_r)
   ```
5. **释放速率上下界**：
   - 下界（基于 rate theory）：Q_min/Δt = 4πDRμf(1-f) / [K⁺(1-f)² - f²/K⁺]
   - 上界（基于 occupancy theory + 空间容量）：Q_max/Δt = 4πDRN_m

**数学模型**:
- 扩散：3D 自由扩散，稳态浓度近似
- 排队：birth-death 过程，状态转移率 λ, μ_i, γ_i
- 占用理论：f 表示需激活受体的最小比例
- 空间容量：有限接收空间限制了最大分子数

**仿真/实验结果**:
- 参数：D=100 μm²/s, R=10-20μm, N_r=400-1000, Q=10⁸-9.1×10⁹, K⁺=0.5 μm³/s, μ=10⁻³ 1/μs
- γ 随 R 增大而减小（进入率降低），随 Q 增大而增大
- γ 随 μ 增大而减小（受体更快回收）
- 提出的 γ 始终大于仅考虑活性受体的 γ₀，差值随 Q 增大而增大
- 下界 Q_min 随 f 增大而增大；上界 Q_min 与 R 呈线性关系
- 与[28]相比，考虑 rejection 后所需最小释放量更大（约 1 个数量级）

### 论文4 (2305.05527)
**标题**: Microparticle-based Controlled Drug Delivery Systems: From Experiments to Statistical Analysis and Design

**核心贡献**:
- 首次将 **MC 理论模型与实际药物递送实验数据**相结合，填补了理论到实践的空白
- 提出了基于 PLGA 微粒（PMP）的 wound dressing CDD 系统的端到端 MC 模型
- 利用**统计分析方法**研究了微粒尺寸 R 的不确定性对药物释放的影响
- 通过实验数据验证了模型的准确性（MSE=3.1×10⁻⁴），优于 Ritger-Peppas 经验模型（MSE=5.2×10⁻³）

**关键方法**:
1. **发射机模型**（PMP 中的药物释放）：
   - 球形扩散方程，Dirichlet 边界条件，均匀初始浓度
   ```
   x(t) = (6D_i/R_i²) Σ_{n=1}^{∞} exp(-D_i n²π² t / R_i²)
   ```
   - 尺寸-扩散系数相关性：D_i = D̂_i R^ω
   - 代入后得到修改形式：x(t) = 6/π² Σ (D̃_i α_n²) exp(-D̃_i α_n² t)

2. **信道模型**（BNC 中的药物扩散）：
   - 一维扩散方程，Neumann + Dirichlet 边界条件
   ```
   h(t) = (8/π²) Σ_{m=1}^{∞} D_o β_m/(2m-1)² · exp(-D_o β_m² t)
   ```
   - β_m = (2m-1)π/(2a)，a 为 BNC fleece 高度

3. **接收端模型**：透明分子计数接收机，累积释放量
   ```
   r(t) = ∫₀ᵗ x(τ)*h(τ) dτ
   ```

4. **统计模型**（微粒尺寸分布）：
   - Gamma 分布：D̃_i α_n² ~ Gamma(γ_n, ζ_n)
   - 推导了 E[r(t;R)] 和 Var[r(t;R)] 的解析表达式
   - KLD 验证：Gamma 分布拟合实验数据（KLD=0.028）优于高斯分布（KLD=0.0285）

**数学模型**:
- 发射机：3D 球内扩散（Fick 第二定律，Dirichlet BC）
- 信道：1D 扩散（Neumann + Dirichlet BC）
- 接收机：线性时不变系统，卷积积分
- 统计：Gamma 分布的随机速率参数，矩匹配

**仿真/实验结果**:
- 实验数据：CBD 从 BNC fleece 中释放（含/不含 PMP）
- 参数：a=3.54mm, μ_R=1μm, σ_R=0.12μm, D_i=1.62×10⁻⁹, D_o=8.13×10⁻² mm²/h
- 模型与实验吻合度极高（MSE=3.1×10⁻⁴）
- μ_r(t) ≈ r(t;μ_R) 验证了假设：同一 BNC 内 PMP 尺寸可视为相同
- 跨 BNC 批次间，σ_r²(t) 随 t 先增后减（可达 10⁻³ 量级）
- ω 值决定 R 能否作为有效的设计参数（ω≈0 时灵敏度高，ω≈2 时不灵敏）

### 论文5 (2508.19739)
**标题**: Molecular Communication for Gastroretentive Drug Delivery

**核心贡献**:
- 提出了首个**聚合物包覆 BNC 的药物释放**解析模型，用于胃潴留药物递送
- 将包覆层建模为 Robin 边界条件的**扩散屏障**（thin-layer 近似），导出了完整级数解
- 通过**湿实验数据**验证了模型准确性（MSE=2.0×10⁻⁴~2.3×10⁻⁴）
- 建立了包覆时间与释放曲线的定量关联，为制造工艺设计提供了理论指导

**关键方法**:
1. **几何建模**：圆柱形 BNC fleece Ω = {(r,ϕ,z) | 0≤r≤R, 0≤ϕ<2π, 0≤z≤Z}
   - R=7.6mm, Z=4.4mm（实测值）

2. **控制方程**：柱坐标系扩散方程
   ```
   (1/D)(∂c/∂t) = (1/r)(∂/∂r)(r·∂c/∂r) + ∂²c/∂z²
   ```

3. **边界条件（Robin 型）**：
   ```
   -D(∂c/∂r)|_{r=R} = h·c(R,ϕ,z,t)
   D(∂c/∂z)|_{z=0} = h·c(r,ϕ,0,t)
   -D(∂c/∂z)|_{z=Z} = h·c(r,ϕ,Z,t)
   ```
   - h = D_c/l（修改的 Sherwood 数），l 为涂层厚度，D_c 为涂层内扩散系数

4. **解析解**（分离变量法 + Sturm-Liouville 理论）：
   ```
   c(r,z,t) = (1/(ZR²π)) Σ_{n=1}^{∞} Σ_{m=1}^{∞} A_{nm} J₀(α_n r) 
              · exp(-D(α_n²+β_m²)t) · [β_m cos(β_m z)+(h/D) sin(β_m z)]
   ```
   - α_n = γ_n/R，γ_n 满足 γJ₁(γ) = (hR/D)J₀(γ)
   - β_m 满足 tan(βZ) = 2hβ / (D(β²-h²/D²))

5. **累积释放量**：
   ```
   F(t) = (2h/(ZR²)) Σ_{n=1}^{∞} Σ_{m=1}^{∞} A_{nm} · [R/α_n · J₁(α_nR) · (β_m cos(β_mZ) + (h/D) sin(β_mZ) + β_m) 
          + R²J₀(α_nR)(h/(Dβ_m) + sin(β_mZ) - h/(Dβ_m) cos(β_mZ))] 
          · (1 - exp(-D(α_n²+β_m²)t)) / (D(α_n²+β_m²))
   ```

**数学模型**:
- 3D 柱坐标扩散方程（轴对称）+ Robin 边界条件
- 分离变量法 + Bessel 函数展开 + 三角级数展开
- thin-layer 近似将薄涂层简化为有效渗透率 h

**仿真/实验结果**:
- 药物：pramipexole dihydrochloride monohydrate（帕金森病/不宁腿综合征药物）
- 包覆材料：聚合物 dispersion，包覆时间 20min / 30min
- 释放介质：0.1mol/L HCl (pH 1.2)，37°C，50rpm
- 拟合得到：D=2.3649×10⁻¹⁰ m²/s, D_c=3.3417×10⁻¹¹ m²/s
- l₂₀=1.25×10⁻⁴ m, l₃₀=3.14×10⁻⁴ m（与包覆时间正相关）
- 三个场景 MSE 均 < 2.4×10⁻⁴
- 涂层显著延长释放时间（无涂层 vs 20min vs 30min）
- D 变化 ±20% 对结果影响较小（低灵敏度）

### 论文6 (2506.22137)
**标题**: On Drug Delivery System Parameter Optimisation via Semantic Information Theory

**核心贡献**:
- 首次将 **语义信息论（Semantic Information Theory）** 应用于 DDS 参数优化
- 将 DDS 建模为分子浓度信道（PIC），提出了基于 **Hill 方程** 的 viability 函数
- 通过**反事实干预（counter-factual intervention）** 量化了 DDS 参数中"有意义"和"无意义"的部分
- 给出了关键 DDS 参数（λ, k_d, k_f, k_b, k_i）的临界值目录

**关键方法**:
1. **PIC（Particle Intensity Channel）模型**：
   - 输入 X：粒子释放概率 p ∈ [0,1]
   - 输出 Y：接收机在符号间隔 τ 内内化的粒子数
   - 信道：Y|X=p ~ Binomial(N, p·P_i)
   - 检测概率 P_i(τ|r₀)：粒子被内化的概率

2. **信道容量**（二进制输入 PIC → Z-channel）：
   ```
   C(τ|r₀) = (1/τ) · max_{p₁} I(X;Y)
   ```
   最优输入分布和容量公式：
   ```
   C(τ|r₀) = (1/τ) · log₂[1 + (1-μ_p) · μ_p^{μ_p/(1-μ_p)}]
   ```
   其中 μ_p = (1-P_i)^{N} 为 1→0 交叉概率

3. **Viability 函数**（基于 Hill 方程）：
   ```
   V(τ) = 1 / [1 + (C_int(τ)/C_th)^n]
   ```
   - C_int(τ) = P_i(τ|r₀) · N(λ,τ)（内化浓度）
   - C_th：50% viability 降低的阈值浓度
   - n：Hill 系数（控制曲线陡峭度）

4. **语义信息定义**：
   ```
   S_ϵ(τ) = min_{i∈I} {C_i(τ) | V_i(τ) ≤ min_{i∈I} V(τ) + ϵ}
   ```
   即在 viability 变化可忽略（<ϵ）的前提下，保留的最小信道容量

**数学模型**:
- 物理层：3D 扩散 + 可逆结合 + 内化 + 降解
- 信息层：PIC → Z-channel → 信道容量
- 语义层：viability 函数 + 反事实干预 → 语义信息

**仿真/实验结果**:
- 默认参数：τ=20ms, λ=1000 s⁻¹, k_d=2×10⁴ s⁻¹, D=5×10⁻⁹ m²/s, a=0.5μm, r₀=1μm
- 五个干预参数及其临界值：
  - λ（释放率）：临界值 2909 s⁻¹，S_ϵ=2.135 bit/s
  - k_d（降解率）：临界值 2343 s⁻¹，S_ϵ=2.126 bit/s
  - k_f（结合率）：临界值 2.9×10⁻¹⁴，S_ϵ=2.071 bit/s
  - k_b（解离率）：临界值 6212 s⁻¹，S_ϵ=2.077 bit/s
  - k_i（内化率）：临界值 3222 s⁻¹，S_ϵ=2.072 bit/s
- Viability 曲线在高参数区域出现平台（过量药物无额外疗效）
- 语义信息随时间 τ 增大呈下降趋势（约 2.5→2.0 bit/s）

## 二、共性模型归纳

6 篇论文虽角度不同，但在 MC 框架下构建 DDS 模型时呈现以下共性：

### 1. MC-DDS 三元组框架

所有论文将药物递送系统映射为 MC 通信系统的三大部分：

| MC 组件 | DDS 对应物 | 功能 |
|---------|-----------|------|
| 发射机 (Tx) | 药物载体 / 纳米机器 / 微粒 / BNC fleece | 释放药物分子 |
| 信道 (Channel) | 细胞外基质 / BNC 基质 / 接收空间 | 分子扩散传播 |
| 接收机 (Rx) | 靶向细胞 / 肿瘤 / 释放介质 | 吸收+内化药物分子 |

### 2. 核心物理过程的统一数学描述

**扩散方程**是所有模型的基础：

| 论文 | 扩散方程形式 | 维度 | 边界条件 |
|------|-------------|------|---------|
| 论文1 | ∂c/∂t = D∇²c | 3D 球坐标 | 自由空间 |
| 论文2 | h(t,τ) = f(r(t),D_X,τ) | 3D | 吸收边界 (RX) |
| 论文3 | h(t,r) = Q/(4πDt)^{3/2}·exp(-r²/4Dt) | 3D | 自由空间 |
| 论文4 | 球形扩散方程 + 1D 扩散 | 3D球+1D | Dirichlet + Neumann |
| 论文5 | (1/D)(∂c/∂t) = (1/r)∂/∂r(r∂c/∂r) + ∂²c/∂z² | 柱坐标 | Robin (3边) |
| 论文6 | 3D 扩散 + 反应（结合/解离/内化/降解） | 3D | 反应边界 |

### 3. 接收过程的排队论模型

论文1和论文3都使用排队论建模受体结合过程：

- **论文1**：每个受体 = M/M/1/1 队列，强调受体是隔离的服务单元
- **论文3**：全局 M/M/N_r/N_m 系统，引入额外的随机运动拒绝率 γ

### 4. 统计信道描述

论文2和论文4都利用随机变量的统计矩来刻画信道：

- **论文2**：均值 m(t,τ) + 方差 σ²(t,τ) → 控释设计
- **论文4**：均值 μ_r(t) + 方差 σ_r²(t) → 尺寸不确定性分析

### 5. 实验验证导向

论文4和论文5都通过**真实的湿实验数据**验证了 MC 模型的准确性，代表了 MC-DDS 研究从纯理论向实验验证的转变趋势。

## 四、基于 MC 的药物递送系统关键挑战

### 挑战1：受体饱和与拥塞控制
- 论文1 和论文3 都揭示了受体数量有限导致的拥塞问题
- 论文1 证明受体不是可复用的资源池，面向 TX 的半球承受了不成比例的高负荷
- 挑战：如何设计动态速率控制机制来避免拥塞，同时保证疗效

### 挑战2：载体的移动性
- 论文2 揭示了药物载体在组织中的扩散运动导致时变信道
- TX 漂离 RX 后，后期需要更多药物才能维持吸收率（tri-phasic 释放）
- 挑战：需要准确的载体定位和运动预测，否则 naive 设计将严重不足

### 挑战3：多尺度建模的复杂性
- 从分子尺度（扩散、结合）到器件尺度（微粒、BNC）到组织尺度
- 论文4 展示了跨尺度建模时参数相关性（如 D_i vs R_i 的幂律关系）
- 挑战：各尺度间参数的耦合关系复杂，实验测量困难

### 挑战4：实验验证的缺口
- 论文4 和论文5 是目前少有的包含实验验证的 MC-DDS 研究
- 多数 MC-DDS 模型仍停留在仿真阶段，缺乏实验数据支持
- 挑战：理论和实验之间的桥梁建设，模型参数的实际可测量性

### 挑战5：个体化治疗与参数优化
- 论文6 提出了语义信息框架，揭示了 DDS 参数中存在"无意义"部分
- 不同患者、不同疾病阶段的生理参数差异大
- 挑战：如何实现 patient-specific 的参数优化，平衡疗效和副作用

### 挑战6：实际几何与边界条件
- 论文5 是唯一考虑实际柱状几何和 Robin 边界条件的工作
- 多数模型假设球对称或自由空间，与实际解剖结构差异大
- 挑战：更真实的解剖几何建模（血管网络、组织界面等）

## 五、信息论指导药物递送参数优化

### 5.1 从语义信息到 DDS 参数优化的框架

论文6 提出了一个完整的信息论指导 DDS 优化的框架：

```
[DDS参数空间] → [PIC信道模型] → [信道容量 C(τ)] 
                                      ↓
[Viability 函数 V(τ)] ← [Hill剂量-响应] ← [内化浓度 C_int(τ)]
        ↓
[反事实干预] → [ΔV = V_actual - V_intervened]
        ↓
[语义信息 S_ϵ(τ)] → [区分"有意义"/"无意义"参数区间]
        ↓
[最优 DDS 设计] → [最小化学预算 + 最大疗效]
```

### 5.2 关键方法论

1. **信道容量作为语义信息的度量**：
   - 传统信息论关注"多少信息被传输"（语法层面）
   - 语义信息关注"多少信息对治疗目标是因果必要的"
   - 信道容量 C(τ) 量化了系统与环境间的最大相关性

2. **反事实干预技术**：
   ```
   干预参数 p → 计算 V_i(τ) → 比较 ΔV
   找到使 ΔV < ϵ 的最小参数变化
   ```
   - 这本质上是一种"参数消融研究"的信息论版本
   - 揭示了哪些参数变化对疗效无影响（可节约化学预算）

3. **Viability-容量权衡曲线**：
   - 论文6 中所有干预参数都呈现类似模式：V(τ) 在 C(τ) 增大到某阈值后进入平台
   - 这个阈值就是语义信息的量化值

### 5.3 语义信息优化的定量结论

论文6 提供的核心定量结果为：

| DDS 参数 | 干预范围 | 临界值 | 语义信息 S_ϵ (bit/s) |
|----------|---------|--------|---------------------|
| 释放率 λ | [1000, 4000] s⁻¹ | 2909 s⁻¹ | 2.135 |
| 降解率 k_d | [1000, 20000] s⁻¹ | 2343 s⁻¹ | 2.126 |
| 结合率 k_f | [1,4]×10⁻¹⁴ | 2.9×10⁻¹⁴ | 2.071 |
| 解离率 k_b | [5000, 20000] s⁻¹ | 6212 s⁻¹ | 2.077 |
| 内化率 k_i | [1000, 5000] s⁻¹ | 3222 s⁻¹ | 2.072 |

**实践意义**：
- 释放率 λ > 2909 s⁻¹ 时，额外药物不再提高疗效（"无意义"的药物浪费）
- 降解率 k_d < 2343 s⁻¹ 时，降解对疗效的影响可忽略
- 各参数临界值对应的语义信息非常接近（约 2.07-2.14 bit/s），表明 DDS 的信息需求具有一致性

### 5.4 与其他论文的信息论联系

虽然只有论文6 直接使用了信息论，但其他论文也有隐含的信息论思想：

- **论文1** 的速率控制本质上是避免"信息过载"（拥塞→信息丢失）
- **论文2** 的 Chebyshev 下界 P_θ ≥ 1-1/β² 给出了信道统计质量的保证
- **论文3** 的上下界区间 [Q_min, Q_max] 相当于 DDS 操作的"可行信息速率区间"
- **论文4** 的 KLD 度量用于评估统计模型的拟合质量
- **论文5** 的参数拟合本质上是在信息论意义上最大化模型与数据的一致性

### 5.5 未来方向

语义信息论在 DDS 中的潜力：

1. **多参数联合优化**：论文6 仅考虑了单参数干预，多参数联合优化可能存在非线性协同效应
2. **时序动态优化**：语义信息 S_ϵ(τ) 随时间演变（论文6 图6），可设计时间自适应释放策略
3. **个性化治疗**：不同患者的 Hill 参数 (C_th, n) 不同，语义信息框架可自适应调整
4. **闭环 DDS**：结合实时反馈（如生物标志物检测），语义信息可用于动态剂量调整
5. **与排队论模型融合**：将语义信息嵌入论文1/3 的排队模型，优化拥塞控制策略
